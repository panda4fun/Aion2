# AION 2 Boss Notifier

Telegram-бот с уведомлениями о полевых боссах и событиях AION 2 (EU, сервер Kromede).
Работает на GitHub Actions, свой сервер не нужен.

## Что делает

- Предупреждает в канал за 15 и за 5 минут до появления босса.
- Предупреждает о событиях: разлом и осада артефактов за 15 и 5 минут, фестиваль Шуго за 5 минут.
- После ежедневного сброса (07:00 UTC, 10:00 МСК) присылает план на сутки.
- Отвечает на команды:
  - `/bosses` - все таймеры боссов;
  - `/next` - ближайшие 3 босса;
  - `/events` - события и сбросы;
  - `/today` - план на сутки.

Таймеры боссов берутся из [NotMeter-Cache](https://github.com/Not4You-Dev/NotMeter-Cache).
Время боссов и событий с фиксированным расписанием скрипт считает сам (`SCHEDULED` и `EVENTS` в коде).
Всё время в сообщениях указано по МСК.

## Как устроен запуск

Workflow [boss.yml](.github/workflows/boss.yml) работает цепочкой.
Каждый запуск длится около 5,5 минуты: шлёт уведомления и через long polling отвечает на команды.
В конце он сам запускает следующий (`gh workflow run`), поэтому бот работает почти без перерывов.
Cron раз в 5 минут нужен как страховка: если цепочка оборвётся, он её поднимет.
GitHub не гарантирует точное время cron, так что после обрыва бот может молчать от нескольких минут до часа.

Состояние (что уже отправлено, offset команд) хранится в `state.json`.
Между запусками workflow сохраняет его через `actions/cache`.

Как остановить бота: Actions → boss-notifier → ⋯ → Disable workflow.
Если отменить текущий запуск вручную, следующий не запустится, но cron через какое-то время запустит бота снова.

## Настройка

В Settings → Secrets and variables → Actions:

| Имя | Тип | Значение |
|---|---|---|
| `BOT_TOKEN` | Secret | токен бота от @BotFather |
| `CHANNEL_ID` | Secret | id канала, например `-100...`; бот должен быть админом канала |
| `MAPS` | Variable | локации через запятую: `1010` Бертрон, `1110` Альтгард, `20` Решанта. По умолчанию `1110,20` |
| `ONLY` | Variable | коды боссов через запятую. По умолчанию список в `boss_notifier.py` |

Коды и названия боссов перечислены в словаре `BOSSES`.
За сколько минут предупреждать о событии, задаёт последнее поле в списке `EVENTS`, например `[15, 5]` или `[5]`. Пустой список `[]` выключает уведомления.

## Локальная проверка

```bash
DRY_RUN=1 python boss_notifier.py
```

С `DRY_RUN=1` скрипт ничего не отправляет, только печатает сообщения и делает один проход.
