# Hidden Cube Overlay

Окно поверх AION 2 с маршрутом по точкам, где появляются Hidden Cube.
Проверенные точки отмечаешь горячими клавишами, не переключаясь из игры.

Точки берутся с [aion2maps.com](https://aion2maps.com/altgard/?L=labels,cube).
Есть Altgard (1371 точка, 59 кубов) и Verteron (1440 точек, 95 кубов).

## Запуск

Нужен Python 3.10+ с tkinter (на Windows он ставится вместе с Python). Сторонние пакеты не нужны.

```bash
py cube_overlay/overlay.py
```

При первом запуске скрипт сам скачает данные в `cube_overlay/data/`.
Обновить их вручную: `py cube_overlay/fetch_cubes.py`.

Игру переключи в оконный режим или в режим «окно без рамки».
В полноэкранном режиме игра перекрывает любые окна, и оверлей не видно.

## Как пользоваться

1. В окне ⚙ выбери карту и районы, нажми «Построить маршрут».
2. Долети до района и кликни по точке, рядом с которой стоишь. Маршрут начнётся с неё.
3. Проверил точку и куба нет: `Ctrl+Alt+→`. Оверлей покажет следующую точку, расстояние, направление по сторонам света и перепад высоты.
4. Нашёл куб: `Ctrl+Alt+↑`. Остальные точки этого куба уберутся из маршрута.

| Клавиши | Действие |
|---|---|
| `Ctrl+Alt+→` | точка пустая, дальше |
| `Ctrl+Alt+↑` | нашёл куб |
| `Ctrl+Alt+↓` | пропустить точку (уйдёт в конец маршрута) |
| `Ctrl+Alt+←` | отменить последнее действие |
| `Ctrl+Alt+=` / `Ctrl+Alt+-` | масштаб миникарты |
| `Ctrl+Alt+H` | скрыть или показать оверлей |

На миникарте север сверху, как на карте игры.
Зелёная точка: цель, жёлтая: следующая, оранжевые: дальше по маршруту, серые: проверенные.
Синяя обводка: точка под водой.

Мышью: клик по точке начинает маршрут с неё, правый клик отмечает точку или снимает отметку.
Перетаскивание сдвигает карту, колесо меняет масштаб. Окно двигается за заголовок, размер меняется за уголок ◢.

Отметки и положение окна сохраняются в `cube_overlay/state.json`.
Когда кубы появятся заново, сбрось отметки в ⚙.

## Что важно знать

- Оверлей не читает память игры и ничего в неё не внедряет. Это обычное окно Windows поверх остальных, античит его не касается.
- Поэтому оверлей не знает, где стоит персонаж. Текущее место: последняя точка, которую ты отметил.
- Предполагаем, что каждая группа точек (`01_A`, `B1` и т. д.) соответствует одному кубу: он появляется в одной из её точек. Поэтому после «нашёл куб» остальные точки группы пропускаются. Если в игре окажется иначе, это легко поменять.
- Маршрут строится жадным обходом с улучшением 2-opt. Подъёмы считаются в 1,5 раза дороже ровного пути.
